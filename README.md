# Xamastry

Xamastry is a free CCNA 200-301 practice platform concept built to grow from a portfolio-quality MVP into a real product.

The planned differentiators are:

- Browser-based Cisco IOS CLI labs with config-state grading
- Groq-powered explanations for missed questions and lab hints
- SM-2 adaptive spaced repetition for weak objectives
- Visual topology labs for multi-device practice
- A modern dashboard for readiness, streaks, and domain coverage

## Tech Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Vercel-ready deployment

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view Xamastry.
